# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils aktuelle veröffentlichte Version bereitgestellt.

## Schwachstellen melden

Bitte Sicherheitsprobleme nicht öffentlich als Issue melden. Verwende auf GitHub unter **Security → Report a vulnerability** eine private Meldung und beschreibe:

- betroffene Version,
- nachvollziehbare Schritte,
- mögliche Auswirkungen,
- bekannte Abhilfen.

Zugangsdaten, echte Kalender-URLs und exportierte Kalenderdaten dürfen nicht mitgesendet werden. Nach Bestätigung wird eine Korrektur vorbereitet und koordiniert veröffentlicht.
